# formulario-web
Formulario web para la Encuesta Clínico-Epidemiológica del Síndrome de Guillain-Barré (Hospital Provincial Saturnino Lora). Permite registrar los datos de las secciones I–VII y guardar automáticamente cada encuesta como una nueva fila en un archivo Excel (.xlsx), con soporte multi-usuario y respaldo local ante fallos de conexión.
